# Unity 3D Maze Ball Lab 01

An interactive 3D maze game built with Unity where the player navigates a ball through a custom-designed labyrinth using mouse controls and custom C# scripts to reach a designated goal point.

---

## 🎮 Game Overview & Features

* **Physics-Based Movement:** Control the movement of the maze sphere using Unity's physics engine (`Rigidbody` & `Collider`).
* **Interactive Labyrinth:** Precision-designed 3D maze environment constructed with custom scale and positioning.
* **Camera System:** Smooth third-person/top-down tracking camera attached to the player sphere.
* **Goal Detection:** Trigger-based win condition upon reaching the center/end of the maze.

## 🚀 Getting Started

### Prerequisites

* **Unity Version:** 6000.0.6f1 (or Unity 2022.3 LTS+)
* **Input System:** Standard Input / Input System Package

### Installation & Setup

1. **Clone the Repository:**
```bash
git clone [https://github.com/saadmohammad-dev/unity-3d-maze-ball-lab01.git](https://github.com/saadmohammad-dev/unity-3d-maze-ball-lab01.git)

```


2. **Open in Unity:**
* Launch **Unity Hub**.
* Click **Add** and select the cloned project folder.
* Open the project using **Unity 6 (6000.0.6f1)** or compatible version.


3. **Run the Game:**
* Navigate to `Assets/Scenes/` in the Project window.
* Open `SampleScene.unity`.
* Press the **Play** button at the top of the Unity Editor.
